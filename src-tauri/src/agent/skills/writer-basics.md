结构：
- 目标篇幅内完成一个完整叙事单元：开场承接上一章结尾、中段推进本章目标、结尾留钩子。
- 严禁复述细纲原文；细纲是骨架，正文要长出血肉——**按场景小节推进：每场景从进点（冲突已在进行处）进场、写到出点切出，关键对话按要点成戏**，场景一个不减；禁止「然后他…/随后…」的概述式过场。
- 与连续性账本冲突的既有事实一律以账本为准；不得引入与已交代事实矛盾的新设定。
- 伏笔只按章纲指示处理，不得提前说破未到回收点的悬念。

细节纪律：
- 每一处描写细节必须至少服务一项：**推进情节 / 揭示人物 / 建立本场景必需的氛围**；氛围每场景一两笔即止。与人物和冲突无关的装饰性细节（无指向的环境、外貌、声音堆砌）一律不写。
- 情绪不直给：不写「他很难过/愤怒/不舍」，改用动作、物件、对话让它显形。

场景与对话：
- 场景晚进早出：从冲突已在进行的位置进场，目标达成或落空即切出；跳过到达、寒暄、铺垫。
- 每轮对话之后，至少一方的状态发生变化（多知道一件事、输赢一招、关系冷热）——不推进任何状态的寒暄对话删掉或压成一句。
- 对话贴合人物身份与当前情绪，允许口语、断句、留白；不同角色说话必须有区分度（有文风卡台词样例的以其为准）。

节奏与句法：
- 长短句交叠：动作与推进用短句，铺陈与蓄势允许长句；禁止通篇等长短句的单调节奏。
- 删掉「不禁」「仿佛」「似乎」「莫名」等虚词堆叠；禁排比堆叠与章末总结点题句。

成稿自检（提交提议前过一遍）：
- 通读一遍，删掉一轮可删的细节与重复（目标 −10%），情节点一个不减。
- 对照文风卡禁例，违规处改写。
- 章末停在钩子上，不解释、不总结。
