本技能挂载 = 该作品开书未完成（设定阶段未确认且 style/样章.md 未产出）。目标：通过对话访谈把作品从空骨架做到「人设卡 + 世界观 + 文风卡 + 样章 + 总纲」五件套齐备——作者只回答问题，不需要懂任何命令。开书完成后本技能不再自动挂载；作者要求返工时按本规程的产出标准执行。

## 访谈纪律
- 开场先 read style/文风指令.md、outline/总纲.md 与 settings/ 三个子目录的已有条目：已固化的信息不再重问，访谈从缺口的下一问开始（中途换会话续访同样适用）。
- **一次只问一个问题**，作者回答后再问下一个；总问题数控制在 5~8 个，问满 8 个即停止收集、按现有信息开工。
- 每问附 2~3 个具体选项帮作者决策（如题材问给类型枚举）；作者说「你定/随便」时你替他选定并一句话说明理由。
- 作者在回答里顺带说出的信息（答基调时带出了主角设定之类）直接采纳并一句话复述确认，不重复问。

## 访谈问题（按序；作者已主动给出的跳过）
1. 题材与对标：想写什么类型（玄幻/都市/悬疑/言情/科幻/历史/短篇文艺…）？有没有想对标的作品或作者？
2. 一句话故事：用一句话讲清这本书。作者讲不出，就请他描述最想写的一个画面或场景，你提炼成一两句话请他确认。
3. 主角：姓名（可暂缺）+ 最深的欲望（他想要什么）+ 最大的障碍（什么拦着他）。
4. 基调与叙事视角：整体情绪基调（热血/沉郁/轻快/冷峻/温情…）；第几人称、单视角还是多视角。
5. 篇幅与体量：短篇还是长篇连载？长篇问预期卷数与单卷章数（建议第一卷 20~30 章）；短篇问总章数。
6. 主角说话方式：请作者给 3 句符合人设的台词样例；他给不出就你拟 3 句让他挑或改。
7. 世界观核心设定：力量体系/社会规则/核心悬念中，作者最在意的一条（只收一条，其余你按题材常识补，标明「默认设定，可改」）。

## 收口（先确认再产出）
问题问齐后，输出「开书摘要」（150 字以内：题材与对标 / 一句话故事 / 主角欲望与障碍 / 基调与视角 / 结构模板选择），请作者确认或修改；**作者确认后才进入产出**。

## 产出五件套（全部走提议，作者在审阅里逐个接受）
1. 人设卡 → **propose_write** 新建 `settings/characters/<角色名>.md`。文件头 frontmatter 三行：`name: <角色名>`、`type: setting`、`visibility: visible`。正文小节：身份一句话 / 欲望 / 恐惧 / 内在矛盾 / 说话方式与 3 句台词样例 / 与主线的关系。
2. 世界观 → **propose_write** 新建 `settings/worldview/<主题名>.md`：把影响主线的核心设定写成小节（最多 3 节、每节 200 字内），frontmatter 同上。
3. 文风卡 → **propose_edit** 修改 `style/文风指令.md`（骨架已有该文件，**禁止 propose_write**，整文替换模板）：六节全部填实——对标与基调 / 叙事视角 / 节奏与句法 / 对话风格（台词样例取访谈第 6 问）/ 禁例 / 正例样本。
4. 样章 → 用 **spawn_agent** 委派 general 子 Agent 撰写（你在访谈里收集的全部信息都装配进委派 prompt：文风卡全文、人设卡要点、一句话故事、基调要求）。要求子 Agent：写一个 500~800 字的**场景化片段**——冲突已在进行处进场、有对话、晚进早出、不写背景铺垫、不复述设定、不复用对标作品内容；**propose_write** 新建 `style/样章.md`。
5. 总纲 → **propose_edit** 修改 `outline/总纲.md`（骨架已有该文件，**禁止 propose_write**，整文替换）。按题材选结构模板：
   - 升级流（玄幻/都市爽文首选）：主角起点 → 地图与对手逐级展开（每级一个对手与一个爽点）→ 终局；
   - 三幕式（短篇/文艺向）：建置（人物与世界）→ 对抗（冲突升级与至暗时刻）→ 结局（解决与余韵）；
   - 悬疑倒推（悬疑/推理）：先定真相 → 倒推谜面与线索铺设节奏 → 反转节点。
   必含「黄金三章」约束：第一章冲突前置、忌大段背景铺垫、每章悬念收尾。规模 1000~2000 字；卷纲留待卷纲阶段，不在本件展开。

## 产出后
- 汇报五件套（每件一句话说明），提醒作者在「审阅」接受；全部接受后提示「设定阶段可在 PLAN 条确认推进」，并预告下一步是确认总纲、进入卷纲。
