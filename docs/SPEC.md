# SPEC · 小说 Harness 平台

> 对齐产物（2026-10-13）：单机自用 / 中文网文长篇 / 长篇优先单卷走通 / 固定流水线 / 双层 git / 规则装配 / Rig 接模型。
> 重设计对齐（2026-10-14）：产品形态演进为「Agent 驱动的写作工作台」——聊天为核心 + 制品面板 + PLAN 条 + 权限两档（D30，原三档收敛）。
> 调研依据：立项期《ai 写小说技术方案》调研报告（原始文件已不在库内）；现行选型结论与来源见 DECISIONS.md 各条目。

## 问题

中文网文长篇作者（首先是自己）用通用大模型写百万字长篇，绕不开三座大山：**一致性崩塌**（20-40 万字开始吃书、人设漂移、伏笔被提前说破）、**流程失控**（没有上位约束，越写越偏直至烂尾）、**成本失控**（上下文乱喂，token 烧钱但不解决问题）。现有方案没有趁手的：马良写作是闭源订阅产品、流程约束最全但不可自持；DeepWrite 开源但缺网文向的流程与一致性深度；裸用 CLI agent 没有作品管理。做一个本地优先的 Harness 工作台：**固定流水线保证"不烂尾"，一致性工程（账本 + 规则装配 + 审校）保证"不吃书"，diff 审阅保证"AI 永远不静默改稿"。**

## 走通路径

新建作品 → 开书访谈（人设卡/世界观/文风卡/样章/总纲）→ 拆一卷卷纲 → 滚动生成章纲（场景级细纲）→ 逐章正文（规则装配上下文 → 草稿 → 精修 → diff 审阅落盘 → 账本回写）→ 审校（一致性 + 可读性第四查 + 去 AI 味精修）→ 修复收敛。

**MVP 交付判据：一卷 3~5 章从新建到审校通过全程可演示，期间任意一步可从 git 历史回溯。**

## 核心机制

1. **主流程状态机**：设定 → 总纲 → 卷纲 → 章纲 → 正文 → 审校。每阶段定义进入条件（上游产物已确认）与退出产物；流程命令按门拦截，聊天路径为软门（Agent 查询 + 提示词约束 + 流程条人工确认兜底，修订 2026-10-14）。卷纲先行、章纲随正文滚动生成，不一次锁死（长篇"边写边长"，来源：马良方法论）。
2. **聊天主操作面**：项目页以一个完整 Agent 的聊天为核心（`/` 技能、`@` 素材、自然语言）；根 Agent 调度用户可配置的子 Agent 团队（成篇创作/系统审校等专职委派，可并行，Agents 页管理），过程以子任务行与子会话标签呈现。产物要进正稿或设定库，一律走 diff 审阅回流（修订 2026-10-14，原「自由旁路」升为一等形态，见 D0-5）。
3. **git 双层**：作品目录 = git 仓库，章节、设定、账本都是 md 文件 + frontmatter。agent 修改统一走 patch → diff 视图 → 接受（自动 commit）/ 拒绝（丢弃）。git 实现用命令行 git（D2）。
4. **连续性账本**：结构化 md，记录角色当前状态（位置/等级/关系/持有物）、已交代事实、伏笔登记、时间线。完稿一章后 agent 从正文提取状态变更，提议 diff 回写账本；下一章装配时注入账本摘要。账本不受上下文窗口限制，是"记忆缺锚"的解。
5. **规则装配**：装配 = 系统提示词（人设/文风，置最前）+ 本卷卷纲 + 本章章纲 + 出场角色卡 + 账本摘要 + 最近章结尾；档位/出场过滤/账本分层可调，预算超限仅软提示（修订 2026-10-14，见 D0-7）。**可见性过滤是红线**：被隐藏或未到开放卷的条目，无论装配怎么设都不进 prompt（lore::is_prompt_visible 出口强制）。2026-10-14 起聊天路径的素材装配由根 Agent 在委派时承担（装配预览视图已退役 D49，装配引擎保留于流程命令）。
6. **审校 agent**：一致性检查（对照账本与设定找矛盾，输出问题清单，逐条 diff 修复）+ 可读性第四查（无功能细节/节奏均质/情节密度/概述腔）+ 去 AI 味精修（按 30% 重点段落）。只做改写，不做平台检测器对齐。
7. **权限与审批**：两档（变更前确认 / 完全访问，会话内切换，D30）+ 作品级覆盖表（会话内权限下拉的「权限例外设置」）。四类操作任何档位永远留人：可见性设置、删除/恢复文件、跳过阶段、装配切全量（硬编码工具层，D32）。bash 白名单可配置，写产物命令拦截并引导 propose_*。
8. **长时目标 /goal**：会话级批量目标（如「把第一卷逐章审校一遍」）迭代执行，轮末独立完成验证器判定真伪完成并续跑未竟，进度横幅可暂停/继续/清除（D31/D34）。

## 非目标（MVP 明确不做）

- 云同步、账号、授权、更新服务（单机自用定位）
- 可配置工作流模板引擎（流水线写死，模板化后置）
- 知识图谱、向量 RAG 自动检索（账本 + 规则装配先顶；单卷验证不需要）
- 拆书、文风比对沉淀（DeepWrite 已验证的方向，后置）
- 平台 AI 检测器对齐、自动过审
- 导出发布格式（txt / 平台对接）、英文 fiction 特化、多人协作、移动端
